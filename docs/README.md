# Documentación del proyecto SIGES

Estructura organizada por objetivo para facilitar la consulta y el mantenimiento de la documentación.

## Mapa de carpetas

| Carpeta | Contenido |
|---|---|
| `git/` | Documentación relacionada con flujo de trabajo Git (`trabajo-git.md`). |
| `despliegue/` | Guías y estrategias de despliegue (`como_levantar_los_servicios.md`, `estrategia_despliegue.md`, `flujo_despliegue.md`). |
| `seguridad/` | Checklist y documentación de seguridad (`seguridad_checklist.md`). |
| `arquitectura/` | Arquitectura, patrones, roles y módulos (`arquitectura_patrones.md`, `accesos_roles_modulos.md`). |
| `inventario/` | Migraciones y mejoras de inventario/bodegas (`migracion_postgresql.md`, `upgrade_v2_manejo_de_bodegas.md`). |
| `mejoras/` | Mejoras, fases e implementaciones (`mejoras_implementaciones.md`, `fases_desarrollo.md`). |
| `bitacora/` | Bitácora de problemas y soluciones (`bitacora_problemas.md`). |
| `generales/` | Documentación transversal (`contexto_trabajo.md`, `pendientes.md`, `roadmap.md`). |
| `diagramas/` | Diagramas del sistema (mantiene su ubicación). |

## Notas

- Los nombres de archivos están normalizados a minúsculas.
- Se conservaron los historiales de git mediante `git mv`.
